## Introduction

Hello, I'm Hyunwoo Lee, a developer with a comprehensive understanding of services, from frontend to infrastructure. Starting with creating mods for my favorite games and sharing them with friends, I've grown by finding ways to implement my ideas.

I've gained hands-on experience in developing various services, such as log analysis systems, file management services, and AI-based services, and operating them both on-premises and in the cloud. This journey has allowed me to become a developer with a thorough understanding of frontend, backend, and infrastructure. 

I have a particular interest in operating Kubernetes clusters, where I've automated cluster configuration using Terraform, set up on-premises servers, and operated a GitHub Action Runner Controller to reduce costs. These experiences, along with obtaining the CKA certification, have expanded my knowledge. 

In service development, I've also automated code management and deployment by setting up CI/CD pipelines and developed an AI-based automatic log monitoring and analysis system to maximize operational convenience. In Alibaba's OpenSandbox open-source project, I identified security issues with the existing configuration file-based approach in real deployment environments like Kubernetes and improved operational convenience and security by switching to an environment variable-based approach.

As a developer, my goal is to enjoy technical challenges and continuously grow. I love learning and applying new technologies to create better services. Additionally, I value collaborating with team members to grow together.
