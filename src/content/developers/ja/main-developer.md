## 自己紹介

こんにちは。フロントエンドからインフラまで直接経験し、サービス全般を理解する開発者のイ・ヒョヌです。<br>
幼い頃から好きなゲームのモードを作って友達と共有したことをきっかけに、
作りたいものができると方法を探して実行する形で成長してきました。

ログ分析システム、ファイル管理サービス、AIベースのサービスなど様々なサービスを作ることから、
これをオンプレミスおよびクラウドで運営することまで直接経験しながら、
フロントエンド、バックエンド、インフラまでサービス全般を理解する開発者に成長することができました。<br>
特に、Kubernetesクラスター運営に興味が多く、terraformを利用したクラスター構成の自動化やオンプレミスサーバー構成、
Github Action Runner Controller運営を通じたコスト削減など多様な経験を積み、
CKA資格取得を通じて知識を拡張することができました。<br>
サービス開発では、CI/CDパイプラインを構成してコード管理とデプロイを自動化する経験もあり、
AIベースの自動ログモニタリングおよび分析システムを開発して運営の利便性を最大化した経験もあります。<br>
AlibabaのOpenSandboxオープンソースプロジェクトでは、Kubernetesのような実際のデプロイ環境で既存の設定ファイルベース方式のセキュリティ問題を発見し、
運営の利便性とセキュリティを改善するために環境変数ベース方式に変更したこともあります。

開発者としての目標は、技術的な挑戦を楽しみながら持続的に成長することです。
新しい技術を学び適用することが好きで、それを通じてより良いサービスを作りたいと思っています。また、チームメンバーと協力して共に成長することを重要視しています。
