## 서비스 전반을 이해하며 개발하는 개발자
<br>
저는 개발 덕후입니다. 중학생 때부터 좋아하는 게임의 모드를 만들어 친구들과 즐긴 것을 시작으로, 여러 서비스를 만들고 공유하며 성취감을 느꼈습니다.

이것저것 만들다 보니 자연스럽게 다양한 기술이 필요해졌습니다. 기능을 위한 백엔드, 사용자에게 보여줄 UI, 서비스를 운영할 인프라까지 직접 경험하면서 서비스 전반의 흐름을 이해하게 됐습니다.

특히 개발 편의 및 서비스 운영을 위해 AWS 같은 클라우드 플랫폼을 이용하기도 하였으며, 비용 절감을 위해 온프레미스 서버로 이전해 Talos, Proxmox, Terraform 등을 사용하여 운영하였습니다.

이 과정에서 쿠버네티스 클러스터 관리에 흥미를 느끼고 백업 자동화, GitOps 기반 운영, TLS를 이용한 보안 강화, 시크릿 관리 시스템 운영, AWS와 온프레미스간 인증 연결 등 여러 작업을 진행하였으며 CKA 자격증 취득을 통해 지식을 넓힐 수 있었습니다.

또한 서비스 개발에서도 CI/CD 파이프라인을 구성하여 코드 관리 및 배포를 자동화 하였으며, AI 기반 자동 로그 모니터링 및 분석 시스템을 개발하여 운영 편의성을 극대화한 경험도 있습니다.

여러 서비스를 처음부터 끝까지 만들고 운영핳본 경험은 팀 프로젝트에서도 활용할 수 있었습니다. 빵빠레와 같은 프로젝트에서는 프론트엔드를 담당하면서도 백엔드의 API 호출 방식에서 렌더링 성능 문제와 보안 이슈를 발견하고, 동료에게 개선을 제안하여 더 나은 서비스를 만들 수 있었습니다.

또한 Alibaba의 OpenSandbox 오픈소스 프로젝트에서 쿠버네티스 등 실제 배포 환경에서 기존 설정 파일 기반 방식의 보안 문제점을 발견하였고, 환경 변수 기반 방식으로 변경하여 운영 편의성 및 보안을 향상시켰습니다.

이러한 경험들은 서비스 전반을 이해하면서 개발하는 것에 도움을 주었고, 주어진 역할 밖을 본 것이 더 넓은 시야로 업무를 수행할 수 있었습니다. 넓은 시야를 가지고 목표를 위해 노력하는 것이 저의 강점입니다.
