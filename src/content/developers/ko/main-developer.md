## 자기소개

안녕하세요. 프론트엔드부터 인프라까지 직접 경험하며 서비스 전반을 이해하는 개발자 이현우입니다.<br>
어릴 때부터 좋아하는 게임의 모드를 만들어 친구들과 공유한 것을 시작으로, 
만들고 싶은 게 생기면 방법을 찾아 실행하는 방식으로 성장해왔습니다.

로그 분석 시스템, 파일 관리 서비스, AI 기반 서비스 등 여러 서비스를 만드는 것부터, 
이를 온프레미스 및 클라우드에서 운영하는 것까지 직접 경험하면서 
프론트엔드, 백엔드, 인프라까지 서비스 전반을 이해하는 개발자로 성장할 수 있었습니다.<br>
특히, Kubernetes 클러스터 운영에 관심이 많아 terraform을 이용한 클러스터 구성 자동화 및 온프레미스 서버 구성, 
Github Action Runner Controller 운영을 통한 비용 절감 등 다양한 경험을 쌓았으며, 
CKA 자격증 취득을 통해 지식을 확장할 수 있었습니다.<br>
서비스 개발에서는 CI/CD 파이프라인을 구성하여 코드 관리와 배포를 자동화하는 경험도 있으며, 
AI 기반의 자동 로그 모니터링 및 분석 시스템을 개발하여 운영 편의성을 극대화한 경험도 있습니다.<br>
Alibaba의 OpenSandbox 오픈소스 프로젝트에서는 Kubernetes와 같은 실제 배포 환경에서 기존의 설정 파일 기반 방식의 보안 문제를 발견하고, 
운영 편의성과 보안을 개선하기 위해 환경 변수 기반 방식으로 변경하기도 했습니다.

개발자로서의 목표는, 기술적 도전을 즐기며 지속적으로 성장하는 것입니다.
새로운 기술을 배우고 적용하는 것을 좋아하며, 이를 통해 더 나은 서비스를 만들어 나가고 싶습니다. 또한, 팀원들과 협업하여 함께 성장하는 것을 중요하게 생각합니다.
