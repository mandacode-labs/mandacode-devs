Meerkat is a log analysis and monitoring system based on AI agents. It collects various log data, analyzes it with AI agents, detects anomalies, and provides real-time alerts.
<br>
The backend is developed in Go and runs in a Kubernetes environment to ensure high scalability and reliability.

It utilizes OpenTelemetry to collect log data, and OpenAI API and RAG technology to perform log analysis and anomaly detection.

It is designed to efficiently store and retrieve log data using PostgreSQL and Milvus.
