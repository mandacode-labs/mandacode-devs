Retrowin is an external storage integration file management system. It works with cloud storage like AWS S3 or your own on-premises storage to upload, download, and manage files. The frontend is developed with React and Next.js, and the backend is implemented with Go to ensure high performance and scalability. It is operated in a Kubernetes environment to provide a stable service.
