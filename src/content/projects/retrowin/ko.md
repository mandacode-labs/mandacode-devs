Retrowin은 외부 오브젝트 스토리지와 연동하여 POSIX 스타일의 파일 관리 인터페이스를 제공하는 파일 관리 시스템입니다. Presigned URL 기반의 2단계 업로드와 원자적 트랜잭션으로 데이터 정합성을 보장하며, Garbage Collection 기능으로 사용되지 않는 파일을 자동으로 정리하여 스토리지 비용을 절감하였습니다. Keycloak OIDC 인증을 활용한 자체 세션 관리로 보안을 확보하였으며, Windows XP 스타일의 레트로 UI를 통해 복고적인 감성과 현대적인 사용자 경험을 동시에 제공합니다.
